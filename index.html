    Proof

    A system that reports success without an artifact is a system that lies.

    Most automation tells you it ran. ACE is built to prove what it produced. Every run is checked against the thing it was supposed to create — a record that exists, a file that opens, a message that sent — and a run that produces nothing is reported as nothing, not as a green tick.

    Customer results are published here only once they are real and the customer has approved them. Nothing above is a projection.
